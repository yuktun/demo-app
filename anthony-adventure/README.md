# 《安東尼大冒險》(Anthony's Adventure RPG) 🎮

專為手機瀏覽器（特別針對 **Android Chrome** 深度調優）設計的原創怪獸探索、收集與回合制戰鬥網頁 RPG！

---

## 🌟 遊戲亮點 (Features)

1. **完整的原創劇情與通關結局**：
   - 唔係只有畫面嘅半成品 Demo，包含由出發、初遇宿敵、拯救村莊、探索水晶洞穴、穿越荒原，直到頂峰神殿擊潰暗影總帥莫爾加斯的完整主線！
   - 通關後解鎖 **榮譽殿堂 (Hall of Fame)**、完整 Staff 製作群謝幕，以及 **通關後自由探索沙盒模式**！
2. **經典 Pokémon 玩法深度復刻**：
   - **地圖探索**：草叢遇敵、NPC 深度互動對話、城鎮精靈診所免費全回復、道具屋買賣、野外寶箱拾取。
   - **怪獸收集與進化**：14 隻全原創怪獸（包含草/火/水三家御三家、兩段進化、野外特有種、稀有種、最終暗影 Boss 王牌、以及守護神獸【艾克西翁】）。
   - **回合制戰鬥系統**：
     - 4 招獨立技能配置（屬性相剋、物攻/特攻/變化、威力、命中率、PP 消耗）。
     - 13 種屬性相剋圖表（火、水、草、電、岩石、地面、冰、幽靈、惡、鋼、龍、聖光、一般）。
     - 膠囊捕獲機制（體力越低、狀態異常越高、高等膠囊越易收服，捕捉時三段搖晃心跳音效！）。
     - 戰鬥經驗值結算、升級數值強化、進化動畫序列！
3. **Android Chrome 與手機深度優化**：
   - **復古掌機人體工學佈局**：上半部為 240×160 復古像素畫布，下半部為拇指觸碰專用的觸控十字鍵（D-Pad）與傾斜 A/B 按鍵，完全不遮擋戰鬥與遊戲視野！
   - **手勢與誤觸防護**：全方位禁用下拉重新整理（`overscroll-behavior: none`）與長按文字彈出菜單（`touch-action: none` / `user-select: none`）。
   - **實體震動反饋**：支援 Android Chrome 的 `navigator.vibrate`，在技能命中、捕獲與按鍵點擊時提供觸覺反饋。
   - **便利輔助鍵**：一鍵切換「👟 跑步模式」、一鍵切換「1.0× / 1.8× 戰鬥快進」、一鍵切換「🔊 聲音」。
   - **支援桌面與 Chromebook**：支援鍵盤 WASD / 方向鍵 + Z (A鍵) + X (B鍵) + C (選單)，並支援滑鼠點擊。
4. **純純自研 Web Audio 合成音效**：
   - 100% 依賴瀏覽器 Web Audio API 實時合成 8-bit / 16-bit 晶片音樂（Chiptune）。
   - 包含城鎮、小徑、洞穴、野外戰鬥、Boss 決戰、勝利號角及結局片尾等 8 首完整 BGM，無需任何外部 MP3 網絡載入，零斷流、零延遲。
5. **本機進度儲存**：
   - 支援隨時手動存檔及重要節點自動存檔至 `localStorage`，隨時關閉瀏覽器亦不怕遺失進度！

## 🕹️ 操作方式

- **手機端 (Android Chrome / iOS Safari)**：
  - **虛擬十字鍵 (D-Pad)**：滑動或按住控制安東尼在四個方向移動。
  - **A 鍵**：對話、調查寶箱、確認選項、發動選中的戰鬥技能。
  - **B 鍵**：取消、返回上一層菜單。
  - **📋 選單**：開啟冒險菜單（檢視怪獸隊伍狀態、使用背包道具、查閱怪獸圖鑑、儲存遊戲進度）。
  - **👟 跑步**：開啟 / 關閉 2 倍速疾跑。
  - **1.0× / 1.8×**：快速切換遊戲運行倍速。
  - **螢幕直接點擊**：支援單手點擊螢幕推進對話與戰鬥。
- **電腦端 (鍵盤 / 滑鼠)**：
  - 移動：`↑ ↓ ← →` 或 `W A S D`
  - A 鍵 (確認/對話)：`Z` 或 `Enter` 或 `Space`
  - B 鍵 (取消/返回)：`X` 或 `Esc`
  - 選單：`C` 或 `M`

## 🚀 啟動與部署

無需安裝任何外部依賴或編譯打包，直接以靜態 HTTP 伺服器打開即可：

```bash
# 在 anthony-adventure 目錄下
python3 -m http.server 3000
# 或
npx serve . -p 3000
```
或直接在瀏覽器以任何靜態 Web 伺服器打開 `index.html`。
